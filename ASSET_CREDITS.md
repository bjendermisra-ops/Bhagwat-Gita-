File page declares CC0 1.0. The original photograph is retained without retouching. Card crops/frames are applied during rendering. https://creativecommons.org/publicdomain/zero/1.0/
- Inter and Noto Serif Devanagari: Google Fonts distributions, SIL Open Font License 1.1. License files are included beside the font binaries.
- Existing logo.png retained from the supplied repository. Existing root prabhupada.jpg is not used in the new studio; the sourced photograph is at assets/art/prabhupada.jpg.

## Content provenance

The verse text, translations and commentary are retained from the repository's existing chapter JSON files. No claim that the supplied commentary is an authorized Prabhupada quotation is made. Duplicate `marathi` fields were recovered by retaining the first as translation and the second as `tatparya_marathi` in the new consolidated dataset. Original chapter files are unchanged.

The supplied corpus contains 689 verse records. See CONTENT_AUDIT.md for absent references. Absences are exposed in the UI rather than filled with invented text.
